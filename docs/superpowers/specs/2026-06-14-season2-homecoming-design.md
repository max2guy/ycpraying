# 시즌2 홈커밍데이 — 설계 문서

**날짜:** 2026-06-14  
**프로젝트:** ycpraying (연천장로교회 청년부 기도 네트워크)

---

## 개요

기존 기도 네트워크 앱(시즌1)에 시즌2 "홈커밍데이"를 추가한다.  
같은 앱 내에서 FAB 메뉴를 통해 시즌 전환이 가능하며, 각 시즌은 완전히 독립된 Firebase 데이터를 사용한다.

---

## 1. 데이터 구조

Firebase Realtime Database 경로를 시즌별로 분리한다. **기존 시즌1 데이터는 변경 없음.**

| 역할 | 시즌1 (기존 경로) | 시즌2 (신규 경로) |
|------|-----------------|-----------------|
| 멤버 | `members` | `s2/members` |
| 채팅 | `messages` | `s2/messages` |
| 접속자 | `presence` | `s2/presence` |
| 중심노드 | `centerNode` | `s2/centerNode` |
| 기도이벤트 | `prayerEvents` | `s2/prayerEvents` |
| FCM 토큰 | `fcmTokens` | 공통 (시즌 무관) |
| 앱 설정 | `appConfig` | 공통 (시즌 무관) |

시즌 상태는 `localStorage("activeSeason")`에 `"s1"` 또는 `"s2"`로 저장한다.  
앱 로드 시 localStorage 값을 읽어 해당 시즌 경로로 Firebase 연결한다.  
시즌2는 빈 데이터에서 새로 시작한다 (기존 데이터 이관 없음).

---

## 2. 테마 전환

`body`에 CSS 클래스를 추가해 CSS 변수를 오버라이드한다.

**시즌1:** 기존 오렌지 계열 테마 유지 (변경 없음)

**시즌2:** 레드 계열 테마

```css
body.theme-s2 {
  --primary: #C0392B;
  --primary-light: #E74C3C;
  --accent: #FF6B6B;
  --bg-gradient-start: #2C0A0A;
  --bg-gradient-end: #1a0505;
}
```

시즌 전환 시 `body.classList.toggle('theme-s2')` 한 줄로 전체 색상 전환.  
인트로 화면, 버블 그래프 색상, 팝업 헤더 등 CSS 변수를 사용하는 모든 요소에 자동 반영된다.

## 3. UI 변경

### FAB 메뉴 (시즌 전환 버튼 추가)

기존 FAB 메뉴 구성에 시즌 전환 버튼을 추가한다.

```
[ ☰ 메뉴 ]
  └─ [ ⚙ 설정 ]
  └─ [ 👤 멤버 추가 ]
  └─ [ 🔄 시즌2 · 홈커밍데이 ]  ← 신규 (시즌1일 때)
       또는
  └─ [ 🔄 시즌1 ]               ← 신규 (시즌2일 때)
```

- 버튼 클릭 시 기존 커스텀 확인 다이얼로그 재사용:  
  "시즌2 · 홈커밍데이로 전환할까요?" / "시즌1으로 전환할까요?"
- 현재 시즌에 따라 버튼 라벨 동적 업데이트

### 인트로 화면

시즌2 진입 시 인트로 화면에 부제 표시:
- 제목: "연천장로교회 청년부"
- 부제: "시즌2 · 홈커밍데이" (시즌2일 때만)

### 상단 UI 시즌 뱃지

캠프 버튼 옆에 현재 시즌을 나타내는 작은 뱃지 표시:
- 시즌1: 뱃지 없음 (기본 상태 유지)
- 시즌2: `S2` 뱃지 표시

## 4. 시즌 전환 흐름

페이지 리로드 없이 Firebase 리스너를 재연결하는 방식으로 전환한다.

```
1. 확인 다이얼로그 승인
2. localStorage("activeSeason") 값 변경 ("s1" ↔ "s2")
3. 기존 Firebase 리스너 .off() 해제
   - membersRef, messagesRef, presenceRef, centerNodeRef
4. 전역 ref 변수를 새 시즌 경로로 재할당
5. members 배열 초기화, currentMemberData = null
6. body 클래스 전환 (theme-s2 추가/제거)
7. D3 그래프 재초기화
8. Firebase 리스너 재등록
9. FAB 메뉴 버튼 라벨 업데이트
```
